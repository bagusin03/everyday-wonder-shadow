The Shadow That Arrived First: one sentence about a small moment of wonder in everyday life, for the make.fun "Everyday Wonder, Two Days to Find the Line" bounty. `main.ts` writes one 86-character sentence to `/output/entry.txt` — nothing else. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> My shadow beat me to the crosswalk by a step, as if it already knew where I was going.

## Run it

```sh
node main.ts
```
